# FullUI bug list (consolidated review)

Source: four read-only file-by-file reviews (server C#, web bundle, Fire TV app, installer/CI), then a second wave of "Netflix-gap" work (section near the end). Duplicates found by several reviewers are merged into one entry. Ordered by importance: fix from the top.

> **Scope decision (user): desktop browser only for now.** Fire TV, TV-remote (webOS/Tizen) and phone-specific items are DEFERRED, not dropped. Deferred IDs: B-03, B-04, B-11, B-12, B-14, B-34, B-35, B-37, B-38, B-39, B-40, B-41, B-42, B-64 to B-74 (Fire TV app), B-61 (legacy TV browsers) and the TV/touch parts of B-29, B-32, B-51, B-54. The Fire TV fix agent was stopped before finishing; its work is not merged. The Fire TV app is **paused / experimental**.

Severity: **CRITICAL** = feature totally broken / security hole / data loss. **HIGH** = likely to fail or misbehave in real use. **MEDIUM** = edge case or robustness gap. **LOW** = polish.

**Status markers** (last column of every table, same words everywhere):

| Marker | Meaning |
|---|---|
| `[FIXED]` | The fix is merged and the code was checked for it (tests exist unless noted). |
| `[PARTIAL]` | Part of the problem is fixed; the note says what remains. |

### Needs a real Jellyfin / Windows PC / device to confirm (current list)

These are the claims no test in this repository can prove. Check them first on a real install.

1. **Injection** (B-06/B-77): the FullUI screen really registers through the File Transformation plugin, works under a Base URL, and the Health page shows "Working". File Transformation's real plugin GUID and status strings after update/uninstall.
2. **Restricted users** (B-24): library access and parental limits really filter every row, search, rating, My List and Coming Soon; the "kid" test (`KidDetector`: library has 5+ mature-rated titles and the user sees 5% or fewer) against real ratings and real users.
3. **Play buttons and navigation** (B-25, B-27, `#/login` fallback route, `viewshow` timing): the web hand-off to the native details page and its Play/Resume buttons.
4. **YouTube** (B-10): trailers actually play in the injected iframe; behaviour with ad blockers and `Referrer-Policy: no-referrer`.
5. **Player assist** (wave 1): Jellyfin's Media Segments data and the `.btnNextTrack` / native skip-button selectors of the installed jellyfin-web version; hide-when-native-shows behaviour.
6. **Playback backfill** (B-20): seeding from `IUserDataManager` on a real, large library; the people (cast/director) lookup time budget on a big catalog.
7. **Scheduled tasks** (B-43): each FullUI task appears exactly once under Dashboard > Scheduled Tasks and runs; run history shows on the Health page.
8. **Windows PowerShell 5.1, `cmd.exe` launcher, SmartScreen / Smart App Control** (B-80, B-90, B-98), `GET/POST /Repositories`, GitHub Actions runs (manifest push to a protected `main`), Ollama downloads.
9. **Ollama** quality and load: row-title stability, embedding prefixes (`search_document:` / `search_query:`), CPU/RAM impact on a modest server.
10. **ABI matrix** on a networked machine (`tools/abi-matrix.sh`), and a smoke test on at least the oldest (10.11.6) and the newest 10.11.x.
11. **Translations**: the Spanish, French and German tables are machine-assisted and need a native-speaker review.
12. **Devices**: touch, phones, webOS/Tizen remotes and Fire TV (all DEFERRED).
